# Contributing

Thanks for helping improve DeepSea Harness.

## Development setup

Install Node.js 20+, npm, Rust stable, and the Tauri 2 Windows prerequisites (Microsoft C++ Build Tools and WebView2 Runtime).

Run npm install, then npm run build and npm run tauri dev.

## Pull requests

- Keep changes focused and explain the user-facing impact.
- Add or update tests when behavior changes.
- Never include API keys, credentials, personal data, or local workspace contents.
- Document security-sensitive behavior and permission changes.
- Run relevant checks before opening a pull request.

Report vulnerabilities privately as described in SECURITY.md.
